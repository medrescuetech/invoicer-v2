## Summary

Fix the manual/historical invoice dialog so line-item totals are written to the **Total** column instead of overwriting the **Discount** column. Rebuild as v2.0.10 and sync to Git.

## Bug

In the manual invoice line-item table, the columns are:

0. Description
1. Qty
2. Unit
3. Price
4. Taxable
5. Discount ($ or %)
6. Total

`_recalculate_lines()` was updating the calculated line total in column `5` — the **Discount** column — instead of column `6` — the **Total** column. This caused the discount cell to be overwritten and the actual Total cell to remain at `$0.00`.

## Fix

`src/invoice_manager/ui/manual_invoice_dialog.py`
- Changed `_recalculate_lines()` to write the calculated total to `self._table.item(row, 6)`. <ref_snippet file="C:\Users\agill\OneDrive\Invoicer\invoicer-v2-temp\src\invoice_manager\ui\manual_invoice_dialog.py" lines="246-248" />
