## Summary

Fix overdue invoices not becoming `paid` after recording a full payment. Rebuild as v2.0.12 and sync to Git.

## Root cause

`PaymentService._update_invoice_status()` was using `invoice.payments` to calculate the total paid. When the `Invoice` object had already been loaded in the UI before the payment was recorded, that collection was stale and did not include the newly-created `Payment`, so the balance stayed positive and `derive_invoice_status()` kept the invoice as `overdue`.

## Fix

`src/invoice_manager/application/payment_service.py`
- `_update_invoice_status()` now queries the database directly via `self.list_by_invoice(invoice)` and a `CreditNote` query, ensuring newly-created payments and credits are always counted.
- Added `CreditNote` to the imports. <ref_snippet file="C:\Users\agill\OneDrive\Invoicer\invoicer-v2-temp\src\invoice_manager\application\payment_service.py" lines="188-201" />
