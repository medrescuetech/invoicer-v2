# Development Record — 2026-09-10 13:28

This record documents the configuration-directory retention work completed in this session.

## Goal

Ensure the application has user-configurable, persisted default locations for data, save/documents, exports and logs via `config.json`, and that these settings survive application restarts.

## What already existed

`src/invoice_manager/infrastructure/config.py` already created and managed a `config.json` file next to the application data tree. It already supported:

- `data_dir` — custom data directory (where the SQLite database lives)
- `documents_dir` — custom documents output directory (where PDFs/Word/Excel files are saved)

The Settings dialog already exposed both of these with Browse and default-reset buttons.

## What was added/enhanced

### `src/invoice_manager/infrastructure/config.py`

- Extended `DEFAULT_CONFIG` with `exports_dir`, `backups_dir` and `logs_dir` keys.
- Added `_custom_directory()` helper that reads a key from `config.json`, creates the directory if needed, and falls back to the default base-dir subfolder when the key is blank.
- Updated `get_exports_directory()` and `get_logs_directory()` to honour custom `config.json` values.
- Added `get_backups_directory()` using the same mechanism.
- Added `set_exports_directory()`, `set_backups_directory()` and `set_logs_directory()` setters that persist the path to `config.json`.

### `src/invoice_manager/application/export_service.py`

- Changed the default export archive target from `self._config.exports_dir` to `self._config.get_exports_directory()` so custom export directories are respected.

### `src/invoice_manager/app.py`

- Changed logging setup to use `config.get_logs_directory()` instead of `config.logs_dir` so custom log directories are respected.

### `src/invoice_manager/ui/settings_dialog.py`

- Added "Exports folder" row with Browse and Use-default buttons.
- Added "Logs folder" row with Browse and Use-default buttons.
- On load, the dialog now populates the exports and logs paths from `config.json`.
- On save, the dialog persists changed exports/logs directories to `config.json`.

### Tests

- Added `tests/infrastructure/test_config.py` tests:
  - `test_custom_data_and_documents_directories_persist`
  - `test_custom_exports_and_logs_directories_persist`

## Usage

The configuration file is stored at:

```text
%LOCALAPPDATA%\InvoiceReceiptManager\config.json
```

(portable mode: next to the executable, inside the `data` folder if present)

You can edit it directly, or use **Tools > Settings > Data & Setup** to change:

- Data folder
- Documents (PDF) folder
- Exports folder
- Logs folder

Empty values in `config.json` revert to the default subfolders under the application base directory.
